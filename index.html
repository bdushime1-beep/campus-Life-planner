About this Project

Summative Assignment - Building Responsive UI

Campus Life Planner is an accessible, client-side web application designed to help university students organize academic deadlines, physical wellness, club projects, and career preparation.

The app features custom regex input validation, safe dynamic search with match highlighting, mobile-first responsive design, localStorage persistence, and accessible keyboard navigation.
